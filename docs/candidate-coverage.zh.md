# 候选能力覆盖索引

[English](candidate-coverage.md)

本索引沿用 2026-10-22 升级调查的 C01–C22 能力编号。候选固定为 DSH `687f282e8625c6b8d11ff58211a90524be2e4317`；Core/Loader 原始来源为 `56b3d4f725681cf4556c1a8695a709cc3b6eed74`。正式[行为锁](../upstream.lock.json)仍为 `639ed015397290b3745d163aafe02ffee4aa3f84`。S1–S9 是明确限定的候选适配，不构成基线晋升。

每行列出实现及负责验证该能力的检查，不宣称每个上游 setup、helper 或断言均已逐项匹配。“已实现”“已执行”“已审查断言”仍遵循各自独立的[兼容性定义](compatibility.zh.md#状态词汇)。不可变的[历史 inventory](upstream-tests.json)及其原有裁决保持不变。原始源码用例通过证明源码执行；native 消费者通过证明该消费者的合同。两者单独都不能证明全部断言等价。

有界的[候选增量审查](candidate-delta-review.json)将变化的合同关联到精确的上游用例身份和具体原生断言，并记录测试准备、辅助函数假设及原生适配。发现门禁在生成映射收据前核对候选源 blob 和原生文件哈希。正式基线的 blob 记录已审查的 Git 比较，发现任务的 checkout 不需要包含较早历史。某项合同审查完成，不代表对应源文件或整个候选清单的全部断言已移植；执行结果另由冻结提交的收据证明。

## C15 保留的后端拒绝

[后端裁决表](development.zh.md#alpha5-独立后端处置)仍定义独立保存模型 DTO/STJ 及 Web 生成的支持范围。S8 metadata API 不会闭合 authored generic DTO 的封闭类型替换、继承展开及多态 discriminator 投影、嵌套 DTO 命名、非 string 字典键、多维数组、保存 Web 二进制附件 metadata，以及尚不支持的 read-only/extension-data/non-public serializer 形态。任意 converter、accessor/constructor 业务逻辑及非 constant initializer 无法从保存事实重建。缺少 source-reference model 或 JSON policy 冲突仍明确报错。Host 实际 STJ 绑定是另一项能力。

[具名集成边界](development.zh.md#剩余支持边界)也继续保留：WPF、Avalonia、Godot .NET 及 Blazor 需要各自证据；Rider 不能证明其他 IDE 行为。这些是保留的支持职责和限制，不是从范围中删除，也不是本次候选新增回退。

## S10 执行及晋升边界

S10 候选源码门禁从固定 Git blob 发现并记录新的、与本机路径无关的 case inventory，通过 ordinal 保留参数化标题重名，每个平台运行四个 shard 并要求精确并集。其 manifest/counts 和 receipt 与历史 inventory 分离。源码 suite 范围是执行边界，不会自动成为 native 断言映射。上游有意跳过的源码文件及文件系统能力 skip 继续明示。

请求候选验证时，[runtime gate](../scripts/verify.py)直接用同次 native JIT 的内存输出比较候选 established 和 upgrade trace，之后继续验证 JIT/AOT 一致性。[CI](../.github/workflows/ci.yml)同时要求正式锁 runtime/source 门禁及候选源码并集。[Portable runner](../scripts/verify-portable-authoring.py)在 Windows、Linux、macOS 消费 Linux 生产的完全相同包/runtime/tool 字节；Windows/Linux 另运行 CLR deployment/multi-entry 和带 AOT 的静态包 caller。macOS 作者/浏览器/native 消费证据不能变成完整 macOS runtime 或 AOT 验收。

执行结果以最终冻结源码/包 receipt 及[验证记录](validation.zh.md)为准。本索引不把待完成运行记作通过，也不授权发布或改锁。晋升仍需按[行为目标升级流程](updating-baseline.md)审查，包括上文保留的能力限制。
