# Cordis.NET.JavaScript

```console
dotnet add package Cordis.NET.JavaScript --version 0.1.0-alpha.2
```

Optional Jint evaluator for Cordis.NET `!!js` configuration expressions. It provides a controlled context bridge but no Node module environment.

Evaluate only trusted configuration. Timeouts are not a security sandbox, and Native AOT support is not claimed. Cordis.NET is independently maintained and is not an official project of DeepSeek, Cordiverse, or Microsoft.
