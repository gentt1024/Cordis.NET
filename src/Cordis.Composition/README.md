# Cordis.NET.Composition

```console
dotnet add package Cordis.NET.Composition --prerelease
```

Configuration, loader, include/group, profiles, deployment resolution, and static module composition for Cordis.NET. Use `StaticModuleResolver` when publishing a Native AOT application.

`SettingsForms` derives live forms over the existing profile editor. Its standard generated controller uses numeric observation revisions and optional expected revisions. Read the [Settings contract migration](../../docs/settings-contract-migration.md) when regenerating clients. Full-configuration hashes keep their separate source-consistency duties.

Cordis.NET is independently maintained and is not an official project of DeepSeek, Cordiverse, or Microsoft.
