# Cordis.NET.Composition

Choose the exact version and feed for this package batch; see [getting started](../../docs/getting-started.md) for package-only use and ownership. Published packages and unreleased candidate feeds are distinct.

```console
dotnet add package Cordis.NET.Composition --version <selected-version>
```

Application composition, coordinated configuration, declaration models, generated Remote bindings and .NET/Web consumers for Cordis.NET. The package carries the author generator, compiler and buildTransitive targets; ordinary plugins do not require Remote. Settings and PluginManager reuse the existing configuration and operation owners. Use `StaticModuleResolver` when publishing a Native AOT application.

`SettingsForms` derives live forms over the existing profile editor. Its standard generated controller uses numeric observation revisions and optional expected revisions. Start with [authoring](../../docs/authoring.md) for Host/client setup and supported model backends. Read the [Settings contract migration](../../docs/settings-contract-migration.md) when regenerating clients. Full-configuration hashes keep their separate source-consistency duties.

Cordis.NET is independently maintained and is not an official project of DeepSeek, Cordiverse, or Microsoft.
