# Cordis.NET.Core

```console
dotnet add package Cordis.NET.Core --prerelease
```

Core Cordis.NET runtime: contexts, plugins, fibers, services, effects, events, reflection, and logging. This package supports static Native AOT applications. Run the repository's `examples/Composition` project from source with its project references; its `PatchResources` helper is not yet in the published packages.

Cordis.NET is independently maintained and is not an official project of DeepSeek, Cordiverse, or Microsoft.
