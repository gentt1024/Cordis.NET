# Cordis.NET.Core

```console
dotnet add package Cordis.NET.Core --version 0.1.0-alpha.2
```

Core Cordis.NET runtime: contexts, plugins, fibers, services, effects, events, reflection, and logging. This package supports static Native AOT applications. Start with the repository's `examples/Composition` project.

Cordis.NET is independently maintained and is not an official project of DeepSeek, Cordiverse, or Microsoft.
